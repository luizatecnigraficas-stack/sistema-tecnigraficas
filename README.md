# Sistema Tecnigráficas

Sistema interno de Tecnigráficas (sistema.sastecnigraficas.com): clientes, cotizaciones, remisiones,
cuentas de cobro, producción, inventario, productos, cartera, finanzas y reportes.

- Es una página web estática (HTML + JavaScript) que usa Supabase como base de datos.
- Netlify publica automáticamente cada cambio que se guarde en la rama `main`.
- Los scripts SQL de Supabase no se guardan aquí porque todo lo de este repositorio queda publicado en la web.
- Los archivos `leeme_v*.txt` explican qué trae cada versión.
